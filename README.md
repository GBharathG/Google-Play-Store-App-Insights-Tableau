# Google Play Store App Insights

## 📌 Project Overview

This project analyzes Google Play Store app data using Tableau to uncover insights related to app ratings, categories, installs, reviews, pricing, app size, content ratings, update trends, and genres.

The analysis follows the requirements defined in the **"App Insights Unlocked: A Data Analytics Challenge"** project brief.

## 🎯 Objectives

- Analyze overall app ratings and categories
- Compare free and paid applications
- Identify highly installed applications
- Analyze reviews, ratings, pricing, and app size
- Examine content ratings and genres
- Study app update trends
- Analyze the relationship between installs and ratings
- Perform sentiment analysis using user review data

## 🛠️ Tools & Technologies

- Tableau Public
- Microsoft Excel / CSV
- Data Cleaning
- Data Visualization
- Exploratory Data Analysis

## 📊 Dataset

The project uses the Google Play Store Apps dataset containing information such as:

- App
- Category
- Rating
- Reviews
- Size
- Installs
- Type
- Price
- Content Rating
- Genres
- Last Updated
- Current Version
- Android Version

A separate Google Play Store User Reviews dataset was used for the sentiment analysis component.

## 📈 Analysis Covered

### Basic Analysis
- Average rating
- Number of unique categories
- App size distribution
- Free vs paid apps
- Content rating distribution
- Top 5 installed apps
- Apps with rating ≥ 4.0
- Average reviews: free vs paid
- Average app size by category
- Apps updated in 2018

### Medium Analysis
- Correlation between installs and ratings
- Average rating by category
- Price vs rating for paid apps
- Rating distribution by content rating
- Genres with apps above 1M installs
- Update frequency
- App size vs installs
- Reviews and ratings
- Content rating: free vs paid
- Top 5 categories by installs

### Advanced Analysis
- Top 10 highest-rated apps
- Update trends over time
- Install ranges vs average rating
- User review sentiment analysis
- Genre vs average rating
